# Stage 5B Round 2A: 8-Dish Visual Confusion Matrix & Classification Analysis

## 1. 概述与视觉分类目标

在 Stage 5A 中，我们使用 3 道 Gold Sample（早餐盘、沙拉、拉面）验证了 Jigsaw Drop 的核心玩法权威（Piece / Group、拖拽拼合、3×3 契合、备餐缓存与订单交付）。

进入 Stage 5B Round 2A，我们正式将 **Gameplay Dish Catalog 扩展至 8 道高品质手绘风格菜品**。

### 为什么需要 8 道菜品？
单靠 3 道菜品（红黄蓝绿基色对比极高）无法真实检验 Jigsaw Drop 的核心玩法：
1. **多图视觉混淆测试**：当场上同时存在两道黄系或两道绿系菜品时，玩家能否依靠质感、切片边缘和标志性食材快速归类碎片？
2. **碎片整理与注意力切换**：从单一菜品目标转向多图并行推进时，玩家是否会发生误拼、找件焦虑或空间锁死？
3. **低对比度与边缘辨识**：测试浅色系米饭、深色系炭烤边缘在拼图咬合线（Tab & Blank Bezier Curves）下的可读性。

## 3. 视觉相似度混淆矩阵 (Visual Confusion Matrix)

评级尺度：
- **1**：完全无关（色相与几何构图反差极大，绝无误认可能）
- **2**：轻微重叠（仅个别点缀物或盘子边缘相似，主体轮廓立辨）
- **3**：中度干扰（同色系或同为主食，需观察 0.5 秒纹理或边缘识别）
- **4**：高混淆风险（同色系主食材，需观察食材切块或调料细节辨析）
- **5**：极度相似（本集合中通过严格 Art Direction 已经根除）

## 4. 关键干扰对 (Distractor Pairs) 深度辨识分析

### 干扰对 1：`dish_curry_rice` (金黄咖喱饭) VS `dish_breakfast` (春日早餐盘)
- **混淆机制**：两者均拥有大面积暖黄金褐调（咖喱汁 vs 煎蛋黄/烤面包边缘），以及白色主食（白米饭 vs 蛋白/白瓷盘底）。
- **解混辨析点**：
  1. **盘型几何**：咖喱饭采用明显的**横向椭圆盘**，盘沿曲率与早餐盘的正圆盘有显著差异；
  2. **食材质地**：咖喱饭右侧为稠厚镜面酱汁与规则方块切丁（土豆、胡萝卜、牛肉）；早餐盘为平整酥脆的吐司方块、卷曲薄培根片与绿叶芝麻菜；
  3. **边缘特征**：咖喱饭碎片边缘带有深棕色酱汁波浪，早餐盘碎片带有褐色面包皮线条。
- **难度结论**：`MEDIUM`。直觉上属于同一色温家族，但微观材质对比强烈，符合“一眼有压力，看第二眼即可确认”的设计要求。

### 干扰对 2：`dish_avocado_chicken_bowl` (牛油果鸡肉碗) VS `dish_salad` (田园沙拉)
- **混淆机制**：两者同属健康蔬菜沙拉碗体系，均有鲜绿蔬菜与明黄玉米粒。
- **解混辨析点**：
  1. **绿系质感差异**：沙拉由蓬松、曲折的**羽状生菜叶**构成；鸡肉碗左上方为**工整扇形排列、刀切平滑的牛油果厚片**；
  2. **肉类与主食标记**：沙拉为纯蔬果轻食+蘑菇+整颗半熟蛋；鸡肉碗拥有**大面积带炭烤焦痕的切片鸡胸肉**与底部细碎藜麦颗粒；
  3. **高饱和色块**：鸡肉碗独有**鲜艳的紫甘蓝细丝**，在任何包含它的切片上都是绝对排他的特征标志。
- **难度结论**：`HARD`。这是测试玩家高阶视觉分类辨析能力的 Gold Distractor。

### 干扰对 3：`dish_shrimp_fried_rice` (鲜虾蛋炒饭) VS `dish_curry_rice` / `dish_breakfast`
- **混淆机制**：测试浅色低对比度碎粒纹理（炒饭颗粒、蛋花）是否会在棋盘上造成辨析疲劳。
- **解混辨析点**：
  1. **暗色高反差边框**：蛋炒饭特意选用了**深宝蓝釉面粗陶盘**，使得边缘碎片（Corner & Edge）拥有极为强烈的深蓝与金黄明度反差，绝不发虚；
  2. **特征点密集散布**：每片碎块均有卷曲的**樱粉色鲜虾**或**圆绿甜豌豆**，没有任何纯白的死区或空洞碎片。
- **难度结论**：`HARD`。

## 5. 棋盘三色并行组合 (Active 3-Dish Combinations) 测试规范

在 Jigsaw Drop 模式下，全剧本单日活跃菜品数始终控制在 **2～3 道**（Catalog Size 8 不等于同时登场 8 道）。

我们定义并验证了以下 5 组具有代表性的 3 菜同场组合：

- **组合 A (经典基线组)**：`[dish_breakfast, dish_salad, dish_ramen]`
  - 红黄蓝绿基色全覆盖，视觉分类门槛最低，适合前期教学与基础验证。
- **组合 B (暖黄系压力测试组)**：`[dish_breakfast, dish_curry_rice, dish_shrimp_fried_rice]`
  - 最大视觉相似度极限测试，检验玩家面对大面积黄色系碎片时的辨识精度与备餐分流策略。
- **组合 C (果蔬生鲜进阶组)**：`[dish_salad, dish_avocado_chicken_bowl, dish_grilled_steak]`
  - 生鲜绿菜与牛油果沙拉碗对照，搭配重色调牛排拼盘作为下沉锚点。
- **组合 D (高对比鲜明组)**：`[dish_tomato_pasta, dish_shrimp_fried_rice, dish_ramen]`
  - 浓红肉酱意面 + 深蓝盘粉虾炒饭 + 琥珀拉面，色彩饱满、轮廓锐利、体验畅快。
- **组合 E (丰盛晚餐主菜组)**：`[dish_grilled_steak, dish_curry_rice, dish_tomato_pasta]`
  - 焦褐炭烤牛排 + 金黄日式咖喱 + 亮红意面，主餐硬菜齐备，视觉层次丰厚。
